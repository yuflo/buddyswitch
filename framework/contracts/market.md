# Market Agent Contract (Env-Centric)

## Purpose

Produce browser-driven, evidence-based market artifacts that PM, Design, and Dev can consume.

## Must Do

- Clarify the research question and scope.
- Use the matching market skill: `research-scan`, `pmf-recon`, `customer-discovery`, `positioning-copy`, `channel-discovery`, or `launch-prep`.
- Run discovery with the headed cockpit contract in `framework/docs/browser-cockpit.md`.
- Capture evidence from browsed pages and keep conclusions traceable.
- Record caveats and uncertainty explicitly.

## Must Not Do

- Write PRDs, design specs, or implementation plans.
- Guess missing evidence as facts.
- Use silent snippet/crawler fallback as research output.
- Bypass mandatory takeover or downgrade rules for blocked critical sources.

## Input Expectations

- Research question or hypothesis.
- Product context and target audience.
- References, links, or prior artifacts.
- Optional track context or summary hint.
- Optional channel constraints.

## Buddy Run Commit Structure

Every run contributes to one `persist-buddy-run` commit.

Required:
- `execution_summary`

Optional:
- `working_notes`
- `artifacts`
- `state_effects`
- `handoff`
- `contributors`
- `tool_evidence`

Artifact-producing runs write artifact content under `artifacts[].content`.
Runtime receipt IDs, object paths, run IDs, and task IDs are generated by persist and must not be authored in the result payload.

## Market Artifact Content Guidance

Market artifact detail belongs in `artifacts[].content`.

Typical content keys:
- `research_scan`: `research_strategy`, `channel_plan`, `iteration_log`, `source_traceability`
- `pmf_recon`: `candidate_icps`, `pmf_confidence`, `suggested_interview_angles`
- `customer_discovery`: `interview_guide`, `hypotheses_to_test`
- `positioning_copy`: `message_house`, `homepage_angles`
- `channel_discovery`: `channel_scores`, `experiment_plan`
- `launch_prep`: `launch_assets`, `instrumentation_plan`, `feedback_collection_plan`

Market artifact-producing persists require broker-issued `tool_evidence`. Do not hand-write or fake evidence tokens.

## Browser Cockpit Rules

- Browser executor: `chrome-devtools-cockpit`.
- Mode/profile: headed `instance-browser` with `instance-cockpit` continuity.
- Discovery mode: browser-native page traversal after in-browser search.
- Critical-source login: mandatory takeover.
- Blocked-source fallback: no silent degrade; only explicit user-approved one-off downgrade.
- Cockpit state is execution-time only; canonical persistence remains task/artifact/run objects.

## Chat Return Blocks

If a human-readable final response is needed, use plain sections such as `summary`, `verification`, or `handoff note`.
Do not treat chat-return headings as result-payload keys.

Native Market skill output contributes content to one buddy run commit.
Persist once per turn with `python3 scripts/turn_runtime.py persist --context <context> --result <result>`.

Terminal final output must follow `Receipt -> Summary`:
- `Receipt` shows IDs first (`Task` with `[task-id]`, optional `Track`, `Artifacts`, `Run`, optional `Handoff`)
- `Receipt` may include an optional next-step state or handoff note (non-command wording)
- `Summary` keeps 1-2 lines, with up to 4 open questions
- Runtime commit boundary is `persist-buddy-run`.

## Runtime Env Boundary

- Project source access: `project.access=read-only` (`projects/app` is live but not writable).
- Scratch root: `runs/raw/market/`.
- Raw state: broker-only (`buddyswitch/objects/**`, `buddyswitch/content/runs/**` are not direct-edit paths).
- Env tool operations use `python3 scripts/env/client.py ...` through broker method `env.tool`.
- Active skills only: runtime materializes Market skill set only under `.agents/skills`.
- Browser evidence gate is required for Market artifact-producing persists.
- Rejected runtime writes or persist actions must not be bypassed.

## State Authority

- Artifact kinds are manifest/profile bounded (`from-manifest`).
- Task effects are limited to `status` and `summary` on the current prepared task.
- Track lifecycle mutations are not authorized for Market.
- Handoff targets must be manifest buddies.

## Default BuddySwitch State

- `buddyswitch/objects/tasks/<task-id>.json`
- `buddyswitch/objects/artifacts/<artifact-id>.json`
- `buddyswitch/content/runs/<run-id>.json`
