# S2 Demand Component Pilot Charter

> Initial state: BLOCKED
> Blocked by: S1 acceptance
> Merge unit: one complete Demand owner cutover

## Acceptance sentence

> Demand domain, state, adapters, assets, exported Skills and local tests live
> under one Demand root; the application selects Demand once; generic hosts
> and other components use typed contributions or Demand Public contracts and
> know no Demand-private detail.

## Entry gate

- S1 accepted;
- current Demand paths/consumers/state/tests/guidance re-traced;
- exact required Daemon/Tool/Web/Skill/cleanup contribution contracts reviewed;
- real Public consumers identified;
- runner co-located-test behavior has an exact RED;
- no Demand feature work shares the stage.

## Owned scope

- `modules/demand/**`;
- smallest passive typed assembly and application component root;
- Demand Public operations/queries;
- Demand Tool/Daemon/Web/Skill/cleanup adapters;
- Demand module tests and affected root proofs;
- direct consumer updates;
- deletion of former packaged Demand paths and guidance.

## Proof

- existing Demand D2/M2/G1 behavioral baseline at affected breadth;
- duplicate/invalid contribution fails application build;
- one Demand Tool/handler/Skill/state writer;
- application imports Demand assembly only;
- no other component imports Demand private;
- package includes runtime/selected Skill assets and excludes module tests;
- complete Actor lifecycle remains clean;
- Demand old paths/references absent.

## Forbidden

- new Demand behavior;
- generic plugin/discovery/container;
- broad host redesign;
- public facade without a real consumer;
- old/new Demand registration coexistence.

## Stop conditions

- a cross-component operation has no clear semantic owner;
- host contribution type must become a generic bag;
- Demand cannot move without changing product behavior;
- a later stage would be required to remove Demand's old live path.
