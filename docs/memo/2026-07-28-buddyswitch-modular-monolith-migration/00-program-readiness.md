- current `docs/arch/**` and executable tests/contracts.

1. current A01–A12 repository/process/lifecycle/owner trace;
2. exact final repository/package/runtime/Actor/state topology;
3. accepted component/foundation/Role decisions;
4. S0–S7 roadmap and stage charters;

## Allowed scope

Only architecture/migration preparation documents and non-mutating repository
inspection. No source, test, current architecture, runtime data, manifest or
launcher change is part of S0.

## Admission gates

### R0 — Current truth

Every current root, process, state location, Actor lifecycle operation, Tool
path, Role/Skill projection, product/capability owner, test and active guidance
consumer is traced.

### R1 — Target truth

The target names:

- one implementation/package root;
- one build/install/runtime identity;
- complete repository tree;
- complete Actor workspace tree;
- component/foundation/Role boundaries;
- state/config/project-mount rules;
- old-root disposition.

### R2 — Migration truth

Each stage:

- leaves a runnable current truth;
- has one owner and acceptance sentence;
- assigns all shared seams;
- has exact predecessor/parallelism rules;
- never relies on compatibility or later cleanup for its claim.

### R3 — Proof and residue

Findings/residue map to decisions, stage owners and direct proof. Complete
Actor lifecycle, package contents, runtime identity, old-path absence and
cleanup are mandatory where affected.

### R4 — Acceptance

Canonical documents agree; the complete affected executable entry baseline is
green; material new S1 boundaries have positive, negative and correspondence
evidence in representative final-shaped probes; no architecture decision is
delegated to the executor; and the maintainer accepts the next authorized
action.

## Exit gate

S0 becomes ACCEPTED only when:

- R0–R4 complete;
- all CRITICAL/HIGH findings have an accepted closure/implementation
  obligation;
- maintainer accepts the target and S1 source-refresh/READY review as the next
  scope;
- no runtime migration has started.

```text
+ package/Actor/lifecycle/residue proof
```
