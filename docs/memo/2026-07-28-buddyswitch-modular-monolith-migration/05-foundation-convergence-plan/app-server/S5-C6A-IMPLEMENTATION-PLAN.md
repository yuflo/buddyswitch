Keep the candidate coherent and runnable. Do not leave an old/new import,
shell fallback, duplicate package asset or deferred consumer for a later C6

- one frozen `./buddyswitch-test full` only after source, runtime, diff and

reported. A bounded in-scope FIX_AFTER_FINAL may correct an attributable C6A
