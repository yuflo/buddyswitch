# S5 C6C Implementation Plan

## Goal

Give Actor workspace publication one product-neutral Foundation owner that
consumes already-resolved bootstrap inputs, preserve the stable Host Control
build path and every observable effect, and delete the retired Launcher
environment owner without introducing RoleHost early.

This is a behavior-preserving refactor. Reuse the GREEN baseline; do not
manufacture a path-move RED.

## Coherent blocks

### 1. Reproduce and classify

Verify exact clean handoff identity, installed runtime correspondence and
zero attributable resources. Rediscover all owner/import, application,
shell-embedded, package, test/support and current-doc representations.

### 2. Separate resolution from publication

Make the Actor Environment owner accept one explicit resolved bootstrap
projection. Keep Role/Skill selection outside Foundation and selected once by
the current application path. Preserve validation and fail-closed behavior;
do not add discovery, a generalized provider framework or a second builder.

### 3. Cut over and replace

Move the complete publication mechanics to the direct Actor Runtime owner,
update the stable application entrypoint and all mechanical consumers, and
delete the retired Launcher owner/import/path/installed projection. Current
Role assets and central Role support remain live only as S6-owned inputs.

### 4. Reprovision before proof

After the coherent `src/buddyswitch/**` mutation, perform one non-editable
build/install/activate/verify cycle before the next public-runner command.

### 5. Prove the vertical slice

Under `$buddyswitch-testing`, dynamically select direct and affected tests.
Prove publication and failure effects, stable shell/application invocation,
code-free selected projection, package correspondence, dependency direction,
old-path absence and cleanup. Batch compatible targets; a remembered node or
path example is not authoritative.

### 6. Review, freeze and FINAL

Review product behavior, one-owner topology, Role cut line, representation
replacement, proof simplicity and resources. Run one frozen
`./buddyswitch-test full`. Use only bounded attributable `FIX_AFTER_FINAL`;
otherwise stop and return.

## Executor authority

The executor owns the shortest owner-correct internal design, equivalent
private file organization, exact mechanical consumers, current test targets
and bounded in-scope repair. The packet freezes outcomes, owner boundaries,
protected behavior and proof classes—not a line-by-line implementation.

## Stop conditions

Stop only if completion requires a protected behavioral/state change, RoleHost
discovery/selection, Host Control/Web/CLI redesign, a compatibility or generic
provider framework, an unexplained boundary failure, or a candidate that
cannot run without later work. Omitted mechanical consumers and corrected
current test targets are executor-owned.
