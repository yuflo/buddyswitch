改造目标：actor runtime 永远不感知 source root，也不回调 launcher CLI

硬边界 Contract

这些不是偏好，是改造验收条件。

维度
当前状态
目标状态
Source root 可见性
actor runtime 可通过 helper 间接碰到 BUDDYSWITCH_REPO_ROOT 或 __file__ 推导 root。
只有 launcher/control-plane 持有 source root。runtime 不读、不传、不推导。
Browser ensure owner
cdp_browser_session.py 在 runtime 中触发 ensure。
browser runtime manager 拥有 ensure/release/stop。CLI 和 broker 都只是入口。
Search 职责
search wrapper 可触发 browser acquisition。
search 只做 query/engine 校验和 search URL 构造，再请求 browser capability。
Cockpit 职责
cockpit proxy 可 shell 回 launcher CLI 来拿 browser_url。
cockpit 使用 broker 获取 browser_url，然后执行 page operation。
MCP 注册
ensure 顺手修复 cockpit MCP，导致 acquisition 与 MCP 配置耦合。
instance start 注册 cockpit MCP。browser ensure 只管理 browser runtime。
回归防线
测试容易只验证 source checkout，不覆盖 sparse runtime 边界。
contract test 明确禁止 runtime-projected code 执行或定位 buddyswitch-codex。

模块职责重分配

每个模块只保留一个清晰身份。

Launcher CLI

人工和 host 入口

  • instance lifecycle
  • workspace projection
  • debug env browser commands
  • 不再被 runtime shell 回调
Runtime Broker

唯一 IPC 边界

  • browser.acquire
  • browser.status
  • browser.release
  • browser.open_url
Browser Manager

runtime owner

  • port/profile/log/pid
  • Chrome startup
  • instance.json browser_port
  • owned/foreign cleanup
Browser Session

page data-plane

  • list/reuse/open page
  • page limit
  • idle TTL
  • no subprocess, no CLI
Search Tool

URL wrapper

  • query validation
  • engine validation
  • build search URL
  • browser capability caller

P0 设计缺口

browser acquisition control-plane 不应存在于 runtime-projected code。当前失败只是这个边界漏洞的具体暴露。

P1 收敛目标

search__open_browser 和 chrome-devtools-cockpit 统一通过 broker 请求 browser capability，不各自触发 ensure。

保留能力

已有 page operation 能力继续保留：Target.createTarget、reuse、page limit、idle TTL。
