Hot spots

哪些地方要看得最仔细

核心不是“后端不够”，而是不要把未被数据支撑的人类协作特征画成事实。第一版只展示可由当前 DTO 支撑或可诚实派生的状态；缺失数据先裁掉或降级，不在这个切片里扩后端。

Derive

Left roster: teammate list

用 /api/actors + /api/roles 生成 teammate roster。

  • 现在有actor_id, role, status, app_server_health, thread_id
  • 可派生role label/scope, online/busy/unhealthy tone, selected state
  • 不要假造avatar, unread count, last DM snippet, per-actor current focus
Keep

Center: selected direct thread

把当前窄右栏 IM 迁到中心区，仍然只做 selected actor direct conversation。

  • 现在有/api/im/session, /api/im/messages, /api/im/events, direct conversation
  • 可改善显示 created_at 和 delivery/wake status
  • 先不做multi-party room/channel, read receipts, message search
Keep

Right card: selected teammate

把 Runtime / Task / Track summary / TUI / lifecycle 合并成 teammate card。

  • 现在有/api/actors/:id/console runtime, Task Sys summary, actor-owned Tracks, IM target
  • 可派生current task callout, recoverable warning, active Tracks count
  • 先不做task history, capability profile, true availability model
Keep

Tracks tab: D Studio read view

Tracks 页面可以直接使用现有 Track Studio 数据。

  • 现在有/api/tracks, /api/tracks/:id, materials, proofs, updates, comments
  • 可展示Track outcome, now.next, blocker, proof/material grids, read-only comment threads
  • 先不做comment composer, Track write actions, collaborators rail
Cut/defer

Admin and mock surfaces

一级 UI 不再呈现 Artifacts / Runtime health / capacity / Workstream / side thread。

  • 删除一级入口Artifacts, Runtime health
  • 降级入口Create Actor, Stop, Resume, Delete, Clear, Copy TUI command
  • 不引入mock metrics, terminal selector, Track comments route, side-thread UI
