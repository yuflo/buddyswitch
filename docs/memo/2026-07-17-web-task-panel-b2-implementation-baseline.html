Implementation boundary

最小垂直切片

生产实现只围绕一个结果：当前任务结束后，最近终态仍在选中 teammate 的 Task card 中可见。

Product proof

  • Active、attention、idle 三态。
  • 默认 recent 两条。
  • 展开五条后可收回。

Contract proof

  • terminal 仅含 completed/canceled。
  • 按 updated_at 倒序。
  • 字段 allowlist 不扩大。

Browser proof

  • 300px 无横向溢出。
  • 默认 card ≤ 220px。
  • 键盘焦点与 aria 状态准确。

Explicit non-goals

  • 无分页、搜索、过滤器。
  • 无 mutation 控件。
  • 无执行摘要、事件或错误详情。
