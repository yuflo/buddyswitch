# Channel Evaluation Rubric

## Core Criteria
- Reachability: Can the founder actually get in front of the target audience?
- Credibility: Will the audience trust the message in this channel?
- Speed: How quickly can the experiment produce a learning signal?
- Cost: What effort or spend is required to run it once?
- Signal quality: Will the response say something meaningful about demand?

## Scoring Guidance
- `1`: weak fit or unrealistic
- `3`: viable but constrained
- `5`: strong early-stage fit with believable execution path

## Warning Signs
- Depends on paid scale from day one.
- Requires a large audience the team does not have.
- Produces vanity metrics without clear learning value.
