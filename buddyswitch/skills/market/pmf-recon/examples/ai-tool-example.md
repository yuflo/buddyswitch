# Example: AI Tool for Founder-Led Outbound

## User request
“Research whether there is PMF potential for an AI assistant that helps solo B2B SaaS founders turn product docs and case studies into highly tailored outbound sequences.”

## Expected execution style

1. Hypothesis frame:
   - ICP candidates: solo SaaS founders, tiny GTM teams, technical founders doing outbound themselves
   - Pain: time cost of personalization and inconsistency of outbound quality
   - Alternatives: templates, generic AI tools, SDR agencies, manual research

2. Source coverage:
   - Reddit communities about SaaS, sales, founder-led growth
   - Hacker News for GTM / AI skepticism
   - Product Hunt for AI outbound tools
   - G2 / Capterra for sales engagement tools if relevant
   - competitor docs and pricing

3. Extract:
   - repeated complaints around bad personalization
   - pain around data gathering and message creation
   - dissatisfaction with generic automation tools
   - whether founders already pay agencies or tools

4. If reaching for X or LinkedIn due to category recency:
   - stop and ask the user to log in if meaningful browsing requires it

5. Output:
   - identify the most likely wedge segment
   - estimate whether the next step should be interviews, a waitlist page, or a manual concierge test
