# Example: B2B SaaS Reporting Assistant

## User request
“Help me validate an AI reporting assistant for small agencies that spend hours every week turning campaign metrics into client-facing summaries.”

## Expected execution style

1. Start with a hypothesis frame:
   - ICP candidates: boutique marketing agencies, solo consultants, freelance media buyers
   - Pain: repetitive reporting and client communication
   - Current alternatives: spreadsheets, Looker Studio, Notion docs, ChatGPT, VA help

2. Scan user-language sources:
   - agency subreddits
   - marketing operations communities
   - Hacker News only if there is tooling discussion

3. Scan alternatives:
   - G2 / Capterra for reporting tools
   - Product Hunt for AI reporting products
   - competitor homepages and pricing pages

4. Build the evidence log.

5. Narrow ICP:
   - maybe boutique agencies with 5–20 clients have the strongest repeated pain

6. Output a PMF memo with a recommendation such as:
   - run 5 interviews with boutique agencies
   - test a concierge service that converts raw metrics into weekly summaries
