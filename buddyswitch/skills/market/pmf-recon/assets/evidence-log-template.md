# Evidence Log Template

Use one block per evidence item.

```markdown
## Evidence Item {{N}}
- Source category:
- Source name:
- URL:
- Date observed/published:
- Public or logged-in:
- ICP hinted:
- Evidence summary:
- Useful quote / paraphrase:
- Pain category:
- Current workaround / alternative:
- Commitment signal:
- Confidence: low / medium / high
- Notes:
```

## Suggested pain categories
- data entry / manual ops
- lead generation / demand discovery
- workflow fragmentation
- reporting / visibility
- collaboration / handoff
- compliance / risk
- content creation bottleneck
- integration friction
- reliability / performance
- pricing / budget mismatch
- onboarding / complexity

## Suggested commitment signals
- pays for current solution
- built internal workaround
- uses multiple tools together
- requested feature repeatedly
- accepted interview / demo / pilot
- joined waitlist / asked for notification
